# RLM Competitor Agency Ad Library

Existing research interface and 17 October 2026 snapshot: 1,779 collected ads, 788 creative families, 71 agencies. Third-party ads belong to their respective owners. This is not exhaustive or real-time coverage and contains no ad performance data.

Published copy excludes adjacent credential files, private storage, and original CSV. No shared API key is included. Optional Claude uses a visitor-provided key and sends selected text to Anthropic. Plain-English search needs no key.

Boards, swipe saves and uploads are local to the visitor browser and origin; existing local-file saves do not automatically migrate. External media may expire. Search-engine noindex is a discoverability request, not access control.

## Swipe mode (added 31 Oct 2026)
Mobile-first Discover mode: open with "Swipe mode" (tabs) or the Swipe button on phones, or add `#swipe` to the URL.
- Pick filters: format (All / Image / Video), who the agency sells to (Immigration firms / Any law firm / Other practice, tagged from ad text on 17 Oct), language, keyword, plus an optional plain-text "says immigration" keyword filter.
- Swipe right or tap Save: adds the ad to the active inspiration board (same Swipe File storage as the grid). Swipe left or tap Skip: hidden for that board's session only, never deleted. Undo reverses the last action.
- Boards, saves and skips live in this browser only. Export / Import a JSON backup from the board menu.
- Immigration firms' own consumer ads are in the separate Immigration Ad Library and are not merged here.
